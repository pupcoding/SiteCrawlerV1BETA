Antes de tudo

Regra de ouro: backup. Baixe o index.html original (e o .htaccess) antes de mexer em qualquer coisa.

  1. Baixe o arquivo original do servidor.
  2. Renomeie para index.html.bak no servidor.
  3. Só então suba o payload como index.html.
  4. Teste em aba anônima e force refresh (Ctrl+F5) — CDN serve versão velha.
cPanel — Gerenciador de Arquivos
  1. Entre no cPanel (/cpanel ou :2083).
  2. Gerenciador de Arquivos → public_html.
  3. index.html ou index.php → botão direito → Renomear → index.html.bak.
  4. Upload → envie o seu arquivo → renomeie para index.html.
  5. Permissões 644 em arquivo, 755 em pasta.
FTP / SFTP (FileZilla)
  1. Host, usuário e senha vêm do painel de hospedagem (21 FTP, 22 SFTP).
  2. Abra o diretório raiz do site (public_html, www ou htdocs).
  3. Arraste o arquivo original pro seu PC como backup.
  4. Envie o payload e sobrescreva o index.html.
  5. Transferência binária pra imagens, ASCII pra HTML.
WordPress — editor de tema
  1. /wp-admin → Aparência → Editor de Arquivos do Tema.
  2. Abra index.php, copie o conteúdo e guarde como backup.
  3. Cole o HTML do payload e atualize.
  4. Imagens: Mídia → Adicionar novo → copie a URL e use no payload.
  5. Editor bloqueado? Gerenciador de Arquivos em /wp-content/themes/seu-tema/.
SSH — o jeito rápido 
ssh usuario@host
cd ~/public_html
cp index.html index.html.bak
wget -O index.html https://seu-hospedagem.com/payload.html
ls -la index.html

Ou scp payload.html usuario@host:~/public_html/index.html.

Onde procurar falhas (checklist manual)
  1. /.env, /.git/config, /backup.zip, /dump.sql acessíveis.
  2. WordPress, plugins e jQuery em versões com CVE pública.
  3. xmlrpc.php aberto (brute force de senha).
  4. Admin sem 2FA e wp-login.php sem rate limit.
  5. phpMyAdmin ou Adminer expostos.
  6. Directory listing ligado (Options +Indexes).
  7. Formulários sem HTTPS e sem CSRF token.
  8. Server: e X-Powered-By revelando versão exata.

Limites do checker

Checagem de navegador é heurística: CORS esconde headers, proxy público falha e a maioria das CVEs exige teste ativo (nmap, nuclei, sqlmap). Use como triagem, não como laudo.
